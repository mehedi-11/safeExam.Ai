SAFEEXAM.AI - AI INCIDENT LOG FEED DOCUMENTATION
================================================================================

This document describes all types of information and events captured and 
displayed in the "AI Incident Log Feed" table on the Teacher Proctoring page 
(TeacherProctoring.jsx).

--------------------------------------------------------------------------------
1. TABLE STRUCTURE & COLUMNS (টেবিলের গঠন)
--------------------------------------------------------------------------------
In the Teacher Proctoring interface, the live log feed table contains three main
data columns:

1. Time:
   The exact local timestamp when the activity occurred.
   Example: [02:35:12 PM]

2. Student:
   The name and unique student ID of the candidate.
   Example: Rahat (1002)

3. Incident / Activity Badge:
   A color-coded pill badge displaying the exact activity type and detailed
   reasoning or detection confidence.

--------------------------------------------------------------------------------
2. EVENT CATEGORIES & COLOR BADGES (ইভেন্টের ধরন ও কালার কোডিং)
--------------------------------------------------------------------------------

A. STUDENT JOIN & RE-ENTRY EVENTS (নীল ব্যাজ / BLUE BADGE)
--------------------------------------------------------------------------------
Badge Style: Blue background with LogIn icon (bg-blue-50 text-blue-700 border-blue-200)

Triggers:
- Initial Join:
  "Student Join: Student joined the exam assessment (Attempt 1)"
  Generated when the student starts the exam for the first time.

- Retake Join:
  "Student Join: Student joined the exam assessment (Attempt 2 / 3...)"
  Generated when the student uses an allowed retake attempt.

- Session Re-entry / Resume:
  "Student Join: Student re-entered / resumed exam session"
  Generated when a student rejoins or reloads an in-progress exam session.
  (Debounced by 60s to prevent feed flooding on rapid page refreshes).


B. EXAM SUBMISSION EVENTS (সবুজ ব্যাজ / GREEN BADGE)
--------------------------------------------------------------------------------
Badge Style: Green/Emerald background with CheckCircle icon (bg-emerald-50 text-emerald-700 border-emerald-200)

Triggers:
- Manual Submission:
  "Exam Submission: Exam submitted manually by student"
  Generated when the student clicks the "Submit Exam" button and confirms.

- Time Expired Auto-Submission:
  "Exam Submission: Auto-Submitted: Time is up (Exam duration expired)"
  Generated automatically when the exam timer reaches 00:00.

- Demerit Points Auto-Submission:
  "Exam Submission: Auto-Submitted: Exceeded 20 demerit points threshold"
  Generated automatically when cumulative violation points reach or exceed 20.

- Instant Block Auto-Submission:
  "Exam Submission: Auto-Submitted: Cell phone detected in camera"
  Generated immediately when an instant-blocking violation occurs.


C. AI DETECTIONS & PROCTORING VIOLATIONS (লাল ব্যাজ / RED BADGE)
--------------------------------------------------------------------------------
Badge Style: Red background with ShieldAlert icon (bg-red-50 text-red-600 border-red-100)

1. AI Camera Object & Face Detections (TFJS MobileNet / COCO-SSD):
- Cell Phone Detection:
  "AI Detection: Cell phone detected in camera"
  Detected mobile phone in frame for > 4 seconds. Triggers instant submission.

- Multiple Persons Detection:
  "AI Detection: Multiple persons detected in camera"
  Detected more than one face/person in the camera stream (+2 demerits).

- Notebook / Study Material Detection:
  "AI Detection: Notebook / Notes detected in camera"
  Detected books, open notebooks, or study materials (+2 demerits).

- Out of Screen Absence:
  "AI Detection: Student left the screen for > 10s"
  Candidate's face/person completely absent from the frame for over 10 seconds.

2. Browser & Environment Security Violations:
- Tab Switching:
  "Tab Switching: Tab hidden for Xs" or "Student switched to another tab briefly."
  Triggers when the student leaves the active browser tab. (>10s triggers instant auto-submit).

- Window Blur:
  "Window Blur: Window blurred for Xs"
  Triggers when the student clicks outside the browser or opens secondary software.

- Clipboard & Shortcut Attempts:
  "Shortcut Activity: Student attempted Ctrl+C/V/X shortcut."
  "Clipboard Activity: Student attempted to use copy/cut/paste on the exam page"
  Triggers when the student attempts to copy questions or paste unauthorized content.
